__`who are we`__

AnalogIO is a group of volunteer software students, supporting the student organization Cafe Analog at the IT University of Copenhagen. 
We create and maintain backend systems and apps for both customers and baristas of Cafe Analog.

__`active projects`__

| Project                                                    | Description                                                                          |
| ---------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| [analog-core](https://github.com/AnalogIO/analog-core)     | The core API driving the coffee card apps                                            |
| [mobile_app](https://github.com/AnalogIO/mobile_app)       | The coffee card app, written in cross-platform Flutter                               |
| [shifty-webapp](https://github.com/AnalogIO/shifty-webapp) | Blazor webapp for managers and board members                                         |
| [azure](https://github.com/AnalogIO/azure)                 | Configuration and Infrastructure as Code for Azure where all our services are hosted |
